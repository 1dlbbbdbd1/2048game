# 2048 经典数字合并游戏

一个基于 Web 的 2048 数字合并游戏，支持 **PWA（渐进式 Web 应用）**，可安装到桌面，离线运行。

---

## ✨ 功能特性

### 核心玩法
- **多种棋盘大小**：支持 4×4、5×5、6×6、7×7、8×8 五种棋盘规格
- **撤销一步**：支持一步撤回，方便试错
- **计时器**：记录每局游戏用时
- **排行榜**：历史最高分记录，支持按棋盘大小筛选
- **多主题切换**：经典、暗夜、海洋、森林四种视觉主题
- **音效反馈**：移动、合并和特殊操作时有音效提示
- **响应式设计**：完美适配桌面和移动端
- **PWA 支持**：可安装到手机桌面，支持离线运行

### 特殊能力（v1.3.0 新增）
游戏提供 **4 种特殊能力**，每种能力都有 **3 种模式** 可选（可在设置中独立配置）：

| 能力 | 操作方式 | 目标 | 默认基础代价 |
|------|---------|------|-------------|
| 🔨 **敲击消除** | 点击一个方块 | 消除该方块 | 方块值 × 50 |
| 🔄 **交换位置** | 依次点击两个方块 | 交换两个方块位置 | 棋盘总分 × 30 |
| 🗑️ **清除小数字** | 一键确认 | 清除所有值为 2 和 4 的方块 | 被清除总值 × 80 |
| ✖️ **翻倍** | 点击一个方块 | 将该方块分值翻倍 | 方块值 × 60 |

### 代价系统
每种能力可选以下三种模式之一：

- **无代价**：任意使用，无需消耗分数或次数
- **扣分模式**：使用时扣除分数，**代价 = 目标值 × 基础倍率 × 累计系数**，每次使用后累计系数增加（越用越贵）
- **限制次数**：每局游戏限定使用次数（默认 3 次，可配置）

能力按钮会根据当前状态（分数不足 / 次数用完 / 棋盘条件不满足）自动禁用。

## 🎮 如何玩

### 操作方式
- **桌面端**：方向键 ↑↓←→ 或 **WASD** 移动方块
- **移动端**：在棋盘上滑动手指（支持上下左右四个方向）
- **特殊能力**：点击游戏页面底部工具栏的能力按钮 → 进入能力模式 → 在棋盘上操作

### 能力使用流程

#### 敲击消除 / 翻倍
1. 点击工具栏的 🔨（敲击）或 ✖️（翻倍）按钮
2. 棋盘边框会变成对应颜色，进入能力模式
3. 点击棋盘上任意一个方块即可完成操作
4. 操作完成后自动退出能力模式
5. 按 **Esc** 可随时取消

#### 交换位置
1. 点击工具栏的 🔄（交换）按钮
2. 点击第一个方块（会高亮闪烁）
3. 点击第二个方块完成交换
4. 点击已选中的方块或按 **Esc** 可取消选择

#### 清除小数字
1. 点击工具栏的 🗑️（清除）按钮
2. 弹出确认框，显示将清除的方块数量和预计代价
3. 确认后立即清除棋盘上所有值为 2 和 4 的方块

### 基础规则
1. 每次移动时，所有方块沿选定方向滑动到最远端
2. 相邻且数值相同的方块会合并，数值翻倍
3. 每次移动后随机空位出现新方块（90% 为 2，10% 为 4）
4. 合出 **2048** 方块即获胜（可选择继续游戏）
5. 当棋盘填满且无可合并方块时，游戏结束

## 📁 项目结构

```
2048/
├── index.html          # 主入口页面（菜单 / 游戏 / 设置 / 排行榜）
├── manifest.json       # PWA 配置文件
├── sw.js               # Service Worker（离线缓存）
├── css/
│   └── style.css       # 样式文件（含 4 种主题、响应式、动画）
├── js/
│   ├── game.js         # 游戏核心逻辑（移动、合并、4 种能力方法）
│   ├── storage.js      # 数据存储模块（设置、排行榜、最高分）
│   └── app.js          # 应用主入口（UI 交互、模式管理、事件绑定）
├── icons/
│   ├── icon.svg        # SVG 图标
│   ├── icon-192.png    # 192×192 PNG 图标
│   └── icon-512.png    # 512×512 PNG 图标
└── README.md           # 项目说明
```

### 模块职责

**[game.js](js/game.js) — 纯逻辑层**
- `Game` 类维护棋盘状态、分数、撤销信息
- 移动算法：方向向量 + 遍历顺序 + 合并判定
- 4 个能力方法：`smashTile()` `swapTiles()` `clearTiles()` `doubleTile()`
- 不操作 DOM，与 UI 解耦

**[storage.js](js/storage.js) — 持久化层**
- `Storage` 对象封装 LocalStorage 操作
- 配置能力默认参数（模式、倍率、递增、次数限制）
- 排行榜 CRUD + 按棋盘大小的最高分追踪

**[app.js](js/app.js) — UI 控制层**
- 页面切换（菜单 / 游戏 / 设置 / 排行榜）
- 统一模式管理：`enterMode(mode)` / `exitMode()`
- 统一代价计算：`getCost()` `estimateMinCost()`
- 动态按钮禁用：`updateAbilityButtons()`（分数不足 / 次数用完 / 棋盘不满足条件）
- 能力提示栏：`showHint()` 实时显示操作说明和当前代价
- 事件绑定：键盘 / 触摸 / 点击

## 🚀 本地运行

### 方式一：直接打开
直接用浏览器打开 `index.html` 即可开始游戏。

> ⚠️ **注意**：PWA 功能（Service Worker）需在 HTTP(S) 协议下工作，直接 `file://` 打开时离线缓存不可用，但游戏可正常玩。

### 方式二：本地 HTTP 服务器

```bash
# 使用 Python 3
python -m http.server 8080

# 使用 Node.js
npx serve

# 使用 PHP
php -S localhost:8080
```

然后在浏览器访问 `http://localhost:8080`

## 🏗 能力配置指南

进入**设置页面 → 特殊功能设置**，可切换 4 个能力选项卡独立配置。每个能力有 3 种可用模式，不同模式下有不同参数：

| 模式 | 参数 | 说明 |
|------|------|------|
| **无代价** | — | 能力无限次使用，不扣分，无额外参数 |
| **扣分** | 基础倍率 | 每次使用的基础代价系数：`代价 = 目标值 × 基础倍率 × 累计系数`。**推荐：5–10** |
| | 递增幅度 | 每次使用后累计系数增加的百分比。例：设 5%，则第 1 次 = 1.00×，第 2 次 = 1.05×，第 3 次 = 1.10×... |
| **限制次数** | 使用次数 | 每局最大可用次数，用完后按钮自动禁用。**推荐：3 次** |

> 💡 **建议初始体验**：先设为"无代价"模式熟悉操作，熟悉后切换"扣分"模式挑战高分。

## 📜 版本历史

### v1.3.4 — 移动端按钮点击失效修复
- 🐛 **修复移动端按钮无响应**：`touchmove` 事件中 `preventDefault()` 未排除按钮区域，导致手机端所有按钮（返回、新游戏、道具等）点击失效
- 🔧 **缩小 `touch-action: none` 作用域**：从 `body` 移至 `.board-wrapper`，仅棋盘区域禁用默认触摸行为，其余区域恢复 `manipulation`
- 🔧 **优化触摸事件判断**：`touchmove` 增加 `button`、`.action-bar`、`.btn-icon` 等选择器排除，确保交互元素正常响应点击，同时保留棋盘滑动防误触功能

### v1.3.3 — 移动端体验优化
- 📱 **按两次返回才退出**：拦截系统全面屏侧滑手势，第一次显示"再按一次退出游戏"提示，第二次才真正返回，避免误操作
- 📱 **窄屏顶栏优化**：新游戏按钮移至底部工具栏，顶栏仅保留返回/分数/静音，按钮加大至 44x44 便于点按

### v1.3.2 — 移动端体验优化
- 📱 **禁用侧滑返回**：游戏页面禁用浏览器侧滑返回手势，避免滑动操作误触发返回
- 🐛 **修复新游戏按钮 ID 冲突**：游戏页"新游戏"按钮与菜单页按钮 ID 重复导致无响应
- 🔧 **能力默认值统一调整为限制次数模式**：所有能力默认改为"限制次数"模式，基础倍率统一为 10，次数为 3 次（清除为 2 次）。与推荐配置保持一致，降低新用户上手门槛。

### v1.3.1 — 修复与优化
- 🆕 **新游戏按钮**：游戏界面顶栏新增"新游戏"按钮，点击弹出确认框，确认后先结算分数再重开
- 🐛 **修复角标泄漏**：按钮因棋盘条件不满足而禁用时，不再错误显示剩余次数角标
- 🐛 **修复清除贴图残留**：清除功能后 2/4 方块 DOM 不再残留在界面上
- 🔧 **交换代价改为卡面值**：交换两个方块的代价 = 两方块面值之和 × 倍率，不再是固定底数
- 🔧 **默认模式改为限制次数**：四种能力默认 3 次使用机会，按钮右下角显示次数角标
- 🔧 **默认倍率降至 10 倍**：全部能力默认扣分倍率从 50-80 统一下调为 10
- 🔧 **提示文案按模式分离**：限制次数/扣分/无限制模式下提示栏只显示对应信息，不再混淆

### v1.3.1 — 按钮角标与状态刷新修复
- 🐛 **修复清除按钮角标残留问题**：退出到菜单调整次数设置后重新开局，角标显示的是旧次数（如仍显示「4×」但已改成 3 次）。根因是 `updateAbilityButtons` 在处理清除按钮时使用 `return` 提前退出，跳过了角标更新，导致上一局的角标值残留。现在每个能力按钮都会走到统一的 `updateBadge` 逻辑，禁用时自动隐藏角标。
- 🐛 **修复开局时按钮状态短暂不一致问题**：之前用 `requestAnimationFrame` 延迟一帧更新按钮状态，开局时约 16ms 窗口内按钮可能处于可用状态。现在 `startGame` 直接同步调用 `updateAbilityButtons`，确保进入游戏页面时按钮状态已正确刷新。
- 🔧 **重构 updateAbilityButtons 为统一入口**：棋盘资格检查 → 模式特定条件 → 角标更新，结构更清晰，避免 early return 带来的角标/状态遗漏。
- ➕ **新增游戏内新游戏按钮**：在静音按钮旁新增新游戏按钮（图标+文字），使用主色调区分。点击后弹出确认框，选择"是"则将当前分数结算到排行榜后开始新游戏，选择"否"则返回游戏。
- 🔧 **HTML 静态资源查询参数更新为 v=1.3.1**，避免浏览器缓存旧版本 JS/CSS
